# NFCV-Android-Command-Sender
A Simple Kotlin in WIP Android App for sending NFCV Command ISO 15693-3

Working on it, 

The entire ISO 15693-3 is locked under a paywall of 2000 dollars, i managed to check nfcV commands and sending it in a RAW mode.
Some Commands are PreInserted in the app but other are specific of the nfc chip that you are using.

it's also possible to format your specific Command.

It's totaly in WIP so if you find any error or feature that you would like to add feel free to commit or ask in the question some feature!

Free NFC for everybody !

also on NXP TAG it's possible to enable i2C mode, very usefull for exchange data with microcontoller or other periferal. This feature is only usable with NFCV Tag
